# 02 - Competitive Research

**Project:** YouTube AI Workspace\
**Version:** 1.0

# Purpose

Understand the current market, identify gaps, and define a clear
competitive strategy.

------------------------------------------------------------------------

# Vision

We are **not** building another "video summarizer."

We are building an **AI Workspace** that helps users learn, build, and
create while watching YouTube.

------------------------------------------------------------------------

# Competitor Analysis

## 1. YouTube Ask

### Strengths

-   Native integration
-   Fast
-   Good for simple Q&A

### Weaknesses

-   No persistent chat history
-   No project generation
-   No code understanding
-   No exports
-   Limited educational workflows

### Opportunity

Become the productivity layer above YouTube.

------------------------------------------------------------------------

## 2. Eightify

### Strengths

-   Fast summaries
-   Chapters
-   Key takeaways

### Weaknesses

-   Static summaries
-   No conversation
-   No RAG
-   No coding support

Opportunity: Interactive AI instead of static summaries.

------------------------------------------------------------------------

## 3. NoteGPT

Strengths - Notes - Flashcards - Mind maps

Weaknesses - Generic content - No transcript fallback - Limited
developer tooling

------------------------------------------------------------------------

## 4. Merlin AI

Strengths - Works across websites - Multiple AI models

Weaknesses - General-purpose assistant - Doesn't deeply understand
YouTube tutorials

------------------------------------------------------------------------

## 5. Sider AI

Strengths - Browser-wide AI - Translation - Summaries

Weaknesses - Not optimized for learning workflows

------------------------------------------------------------------------

------------------------------------------------------------------------

# SWOT Analysis

## Strengths

-   RAG grounding
-   Transcript fallback
-   Developer-friendly
-   Premium chat experience

## Weaknesses

-   API costs
-   OCR complexity
-   Dependency on transcript/audio quality

## Opportunities

-   Chrome Web Store
-   Students
-   Developers
-   Researchers
-   Web app expansion

## Threats

-   Native YouTube improvements
-   AI browser assistants
-   Rising LLM costs

------------------------------------------------------------------------

# Monetization Strategy

Free - 20 chats/day - Gemini - Groq

Pro - GPT-5.5+ - Claude - OCR - Vision - Workspace Sync - Unlimited
chats

------------------------------------------------------------------------

# Success Metrics

-   Chrome Store installs
-   DAU
-   Paid conversion
-   Average session duration
-   Project generations
-   PDF exports

------------------------------------------------------------------------

# Conclusion

Our biggest differentiator is not AI chat.

It is turning passive video consumption into active creation through a
persistent AI workspace.
